# XtraCover B2E React Landing Page

A responsive React and Tailwind CSS implementation based on the supplied landing-page reference.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Simple folder structure

```text
src/
  components/          Landing-page sections
    ui/                Small reusable UI helpers
  data/                Navigation and page content
  App.jsx              Section composition
  index.css            Tailwind import and shared styles
  main.jsx             React entry file
public/
  assets/              Landing-page visual assets
```

## Included sections

- Header and responsive navigation
- Hero with business device dashboard
- Customer segment trust bar
- About and business benefits
- Multi-category device showcase
- Warranty section
- Laptop configurations
- Industries
- Procurement process
- Review slider
- FAQ accordion
- Business enquiry form
- Final CTA and footer

## Notes

- The enquiry form currently displays a frontend confirmation. Connect it to the required API, CRM, or email service for live submissions.
- Review content is sample copy and should be replaced with verified customer feedback before publishing.
